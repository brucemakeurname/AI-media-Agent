# Named animation profiles

`animation.js` is the executable source. This folder documents the reusable motion vocabulary so
the renderer or a future skill can select an existing profile without inventing new animation.

- `retail-reveal`: frame lift, content stagger, yellow rule draw.
- `product-focus`: retail reveal plus packshot rise.
- `offer-emphasis`: retail reveal plus badge scale and short sweep.
- `gallery-stagger`: retail reveal plus left-to-right product tile stagger.
- `metric-fill`: retail reveal plus progress bar fill.
- `retail-exit`: shared fade/lift exit during the last 0.50 seconds.
