# Blue Professional video bundle

An analytical executive system: warm cream `#FDFAE7`, cobalt `#1E2BFA`, and near-black `#111111`. Information lives in quiet blue-tinted cards with precise cobalt rules and a single progress-stripe accent.

- Display, numbers, and UI chrome: Space Grotesk; reading copy: Inter.
- Use 10–14px radii, a 1.5px cobalt-tint border, and no shadows.
- Keep cobalt structural: labels, key metrics, progress, and one decisive panel. The rest of the frame remains calm cream.
- Reserve atmosphere (rings and diagonal geometry) for cover, divider, and closing moments only.
- Optional image slots use only resolved article images. All CSS is scoped and every type size uses `var(--v-text-scale)`.
