# Bold Poster

Use a white / ink / tomato-red / off-white poster palette only: `#FFFFFF`, `#1C1410`,
`#D8000F`, `#F5F2EF`. Display is Shrikhand 400 (tilted); body is Libre Baskerville;
chrome is uppercase Space Grotesk. Keep surfaces square and flat. The only shadow is the
stacked text shadow on display type set over a red panel.

Supported treatments: six native poster layouts (`hook`, `vignelli-stat`, `data-flow`,
`callout`, `timeline`, `outro`) plus nine re-skinned text/data motion layouts. Do not add
photo-implying layouts: Bold Poster forbids fabricated imagery. Capture layouts remain engine-owned.

Every text size must use `var(--v-text-scale)` when adjusted in this bundle. Preserve the red
progress bar, one dominant display moment, and substantial negative space outside the financial grid.
