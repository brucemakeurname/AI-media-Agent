# Capsule video bundle

Capsule is a sun-bleached cream editorial system built from outlined, lifted pills. Bodoni Moda carries
sentence-case headlines and numerals; Space Grotesk carries uppercase tracked chrome.

- Every container is either a `9999px` pill or 2rem pill-card with a 2px ink outline.
- Use candy fills (coral, lime, lavender, sky, violet, yellow, peach, mint) on pills and stat values, not headlines.
- Content pills receive only a small hard ink-offset shadow; decorative pills remain flat.
- Every frame uses cream atmosphere: radial candy glows, fine grain, and rounded visual language.
- Optional image slots remain conditional on `imageUrl`; all type sizes are scaled through `var(--v-text-scale)`.
